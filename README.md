# Arithmetic-Logic-Unit
This lab focuses on designing and implementing an 8-bit Arithmetic Logic Unit (ALU) with a finite state machine (FSM) using VHDL for an FPGA system. The ALU performs various arithmetic and logic operations based on opcode input and displays the output on a 7-segment display.
